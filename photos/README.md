Web Technologies 2026 project. Originals are stored here unmodified
(4080 × 3060 or 4096 × 3072); the site references them by the file name on the
left. The right-hand column is the name the camera gave the file, which also

The originals are what the lightbox opens. `photos/thumbs/` holds a 640 × 480
JPEG preview of each one, used only by the card grid on `buildings.html` so that
page does not have to download 79 MB of originals to show a page of small photos.

The mapping lives in `map.js` (`photo` on each building, `photo` on each
place inside a building). Keep this table in step with it if a photo is
replaced.
